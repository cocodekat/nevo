Functions

Why do we have functions?

Functions are a very important part in code. It allows us to easily reuse code instead of having to rewrite it over and over again.

How do we use it?


Now, let’s try it out ourselves. First, we need to create a function. For example, if we want a function that prints ‘hello’, we can do: 

_main() {}

the code will always start at _main, if this function is not defined the compiler will give critical errors.
Everything inside of the brackets {} is part of the function.
The function name has to start with an underscore _ , to make sure our computer has no chance of mixing code.
Lets now try to print ‘hello’ 
_main() {
print("hello")
}

Parameters


if we for example want to take a variable and print that, we could do: 
_main() {
num x = 1
jump _hello(x)
}

_hello(var) {
print(var)
}

this will print whatever we put into x. We ofcourse do not need a second function to print a variable but this is simply for demonstration purposes.
