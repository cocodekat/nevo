Printing

Released on 2025-10-11

Why do we have printing?

Printing is very usefull for developers. It is mostly used for debugging or terminal apps

How do we use it?

Now let’s try it out ourselves. Printing is quite simple. To print a string we simply do: 
print(“Hello world!“)!


To print a variable, we can do: 
print(var)


We can also print newline characters, they must be inside of a string like this: 
print("\n")
